 
 # PDF-Pages-Extracteur
 
 Ce script permet d'extraire les pages d'un fichier pdf en contournant le mot de passe "admin" (attention, il ne contourne pas le mot de passe utilisateur s'il y en un). 
 
 On peut extraire une série de pages avec un schéma 3,5-8,10 où les traits d'union signifie de 5 à 8. On aura donc avec cette instruction un fichier résultat contenant les pages 3,5,6,7,8 et 10.
