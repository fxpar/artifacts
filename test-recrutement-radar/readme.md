# Test recrutement

POC: outil d'évaluation. Exemple de projet à faire créer à des RH pour voir le niveau de maîtrise en pilotage d'IA.

[👉 DEMO](https://fxpar.github.io/artifacts/test-recrutement-radar/test-IA.html)

Fonctionalité :

1. charger plusieurs évaluation (dimensions et items)
1. remplir des évaluations (stockées localement, dans le navigateur)
1. afficher un graphique radar avec superposition d'évaluations

## Version pré-remplie
Contient déjà un exemple fictif de référentiel d'évaluation IA

## Version simple

Nécessite d'ajouter des référentiels.

## Compétences évaluées

### Capacité à cadrer le projet
L'étudiant.e défini les dimensions du projet qui seront laissé aux développeurs et ce qui relève du POC.
Exemple: 
#### Partie traitées
* l'import de référentiel
* le remplissage de l'évaluation
* la création du graphique

#### Partie non traitées
* la sécurité
* le déploiement
* le stockage réél

L'étudiant.e maîtrise le vocabulaire pour définir ces parties de gestion de projet informatique, soit directement, soit après discussion avec l'IA. 

### Capacité à formuler les demandes
#### Rédaction du Prompt initial
* Rédige un prompt avec les spéficicités de manière claire, le langage à utiliser, le contexte, soit directement, soit en conversant avec une IA de manière structurée. Dans ce second cas, la direction des questions pour parvenir à un prompt clair est évaluée.
* Défini la stratégie de construction du résultats sur plusieurs demande
* Cadre la qualité et les formats de la conversation avec l'IA pour limiter le frictions et anticiper le risques d'errance et d'erreur

#### Conduite de la conversation
* Organise les questions en anticipant les risques d'erreurs de l'IA
* Permet à l'IA de corriger
* Organise des cycles de validation

### Capacité à faire du code augmenté
* Remonte les erreurs via la console
* Intégre le code sur plusieurs réponses à la suite par copier-coller corrects
* Test régulièrement le code fourni
* Conserve les versions de développement
