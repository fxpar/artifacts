# JSON Visualizer

[👉 Ouvrir l'outil](https://fxpar.github.io/artifacts/json-visualizer/)

Petit outil sans prétention, créé pour une vidéo : afficher un JSON **en grand et en couleur** pour pouvoir zoomer dessus et le rendre lisible à l'écran.

## Fonctionnalités

- Coloration personnalisable : clés, chaînes, nombres, booléens, `null`, accolades, crochets, ponctuation (couleur et gras).
- Taille de police et indentation réglables (y compris une indentation qui grandit à chaque niveau).
- Thèmes prédéfinis : sombre, clair, monochrome, néon.
- Formater, minifier, copier ; dépôt d'un fichier `.json`.

## Confidentialité

Tout se passe dans le navigateur.

## Bibliothèques

Aucune (HTML, CSS et JavaScript seuls).
