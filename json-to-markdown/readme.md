# JSON → Markdown

[👉 Ouvrir l'outil](https://fxpar.github.io/artifacts/json-to-markdown/)

Convertit n'importe quel fichier JSON en Markdown lisible : les clés deviennent des titres, les tableaux des listes, et les URL restent des liens cliquables.

Utile pour relire ou transmettre à une IA (ou à un humain) des données structurées sans la syntaxe JSON.

## Utilisation

1. Collez du JSON ou déposez un fichier `.json` (un exemple est disponible).
2. Cliquez sur **Convertir en Markdown**.
3. Copiez le résultat.

## Confidentialité

Conversion 100 % locale, dans le navigateur.
